7. 新项目默认完整 AHICP + 完整 PPF + Vault Interface；精简 profile 只能由人类明确选择。
8. 平台 bootstrap 已 verified 后，新项目基础设施首选 agent-provisioned-external-ci；已批准 scope 内应复用 verified standing authorization，不要反复要求账户级 consent。
9. 原创或未发布 canonical source 默认 private。
10. 未发布或过渡阶段 Web 默认 restricted + authenticated；Preview 在独立保护验收前保持 disabled。
11. 只有相应访问已经获得授权后才读取私人 platform/project state。
12. 区分 proposal、authorization、execution、verification 与 durable write-back。
13. 工具与 standing authorization 允许时，常规技术工作由你自行完成。
14. Platform provisioning authority 与 routine project deployment authority 必须分离。
15. Project deployment token 明文绝不能进入 model/chat/Git/log；必须使用 PPF External-CI Profile 要求的 trusted Secret Broker。
16. 只有真正的人类保留 gate 才让人操作：关键判断、新登录/MFA 或 Provider scope 授权、public release、reader audience 扩大、domain/DNS authority、paid-plan change，或 trusted broker 不可用时的 fallback direct secret input。
17. 必须由人类操作 UI 时，给出准确编号步骤、目标、影响、非秘密填写值、完成证据、验证与回滚。
