Inquiry Publishing Project Starter
Composition · Adoption · Upgrade

把探究、出版与项目升级组织成一个可开始的组合入口。

Inquiry Publishing Project Starter 是一个组合、采用和升级层。它帮助项目从 AHICP、PPF 与 Vault Interface 选择合适的组成方式，但它本身不是第四套规范性框架。

Starter 做什么

Starter 把多个独立系统连接成一个可以实际开始的项目结构。它提供模板、配置、配置文件、升级规则和可验证的机器可读状态，让项目能够知道自己采用了哪些组件、来自哪个来源、处于什么状态。

组合

根据项目目标选择研究、出版、研究写作或完整研究出版配置。

采用

记录项目实际采用的上游版本，而不是把不同系统的规范复制到 Starter 中。

升级

保留来源提交、项目采用提交和采用状态，帮助升级过程保持可解释、可检查。

交接

让新的协作者能够从项目文件、规范和机器可读状态继续工作。

三层关系

AHICP · 人主导的 AI 探究协议
负责探究、证据、决定、批准、交接和责任边界。
PPF · 个人出版框架
负责源材料、构建、发布、版本和可重建的出版过程。
Vault Interface · 私人控制平面接口
为需要私人上下文和个人控制的项目提供接口层；它不等于公开内容。
Starter · 组合入口
负责把这些系统按项目需要组合、采用、验证和升级。

适合哪些项目

它适合需要长期上下文、可检查协作和稳定出版流程的个人研究、学术写作、研究型书籍、知识管理和复杂创作项目。项目可以只启用其中一部分；配置描述的是组合方式，不是项目价值。

Composition · Adoption · Upgrade

One starting point for composing inquiry, publishing, and project upgrades.

Inquiry Publishing Project Starter is a composition, adoption, and upgrade layer. It helps a project choose how AHICP, PPF, and Vault Interface fit together without becoming a fourth normative framework.

What the Starter does

The Starter connects independent systems into a project structure that can actually be adopted. It provides templates, configuration, profiles, upgrade rules, and machine-readable state so a project can identify which components it uses, where they come from, and what state they are in.

Compose

Choose research, publishing, research-book, or full research-publication profiles according to the project.

Adopt

Record the upstream revisions a project actually adopts instead of copying independent normative systems into the Starter.

Upgrade

Preserve source commits, adopted commits, and adoption state so upgrades remain explainable and inspectable.

Handoff

Make it possible for a new collaborator to continue from project files, specifications, and machine-readable state.

How the layers relate

AHICP · Human-led AI inquiry protocol
Governs inquiry, evidence, decisions, approvals, handoffs, and responsibility boundaries.
PPF · Personal publishing framework
Governs source material, builds, publication, releases, and rebuildable publishing.
Vault Interface · Private control-plane interface
Provides an interface for projects that need private context and personal control; it is not public content.
Starter · Composition entry point
Composes, adopts, validates, and upgrades these systems according to project needs.

What it supports

The Starter is suited to personal research, academic writing, research books, knowledge management, and complex creative work that needs durable context, inspectable collaboration, and a stable publication process. A project may activate only part of the stack; a profile describes composition, not project value.
