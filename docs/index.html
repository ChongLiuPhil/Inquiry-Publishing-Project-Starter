Inquiry Publishing Project Starter 是一个组合、采用和升级层。它帮助项目从 AHICP、PPF 与 Vault Interface 选择合适的组成方式，但它本身不是第四套规范性框架。

Starter 做什么

Starter 把多个独立系统连接成一个可以实际开始的项目结构。它提供模板、配置、配置文件、升级规则和可验证的机器可读状态，让项目能够知道自己采用了哪些组件、来自哪个来源、处于什么状态。

组合

根据项目目标选择研究、出版、研究写作或完整研究出版配置。

采用

记录项目实际采用的上游版本，而不是把不同系统的规范复制到 Starter 中。

升级

保留来源提交、项目采用提交和采用状态，帮助升级过程保持可解释、可检查。

交接

让新的协作者能够从项目文件、规范和机器可读状态继续工作。

三层关系

AHICP · 人主导的 AI 探究协议
负责探究、证据、决定、批准、交接和责任边界。
PPF · 个人出版框架
负责源材料、构建、发布、版本和可重建的出版过程。
Vault Interface · 公共元数据契约
提供与提供商无关的公共元数据 Schema、模板和验证器；私人 Vault、工作记忆和部署控制平面仍留在项目私人状态中。
Starter · 组合入口
负责把这些系统按项目需要组合、采用、验证和升级。

默认项目姿态

新项目默认采用完整 AHICP + 完整 PPF + Vault Interface。原创或未发布源文件默认保持 private；Continuous Web 可以同时准备，但在得到明确公开发布授权前默认 restricted，并由 Cloudflare Access 或等效的服务端访问策略保护。仓库只保存访问策略引用，不保存实际密码或秘密。精简 profile 只有在人类明确选择时才使用。

适合哪些项目

它适合需要长期上下文、可检查协作和稳定出版流程的个人研究、学术写作、研究型书籍、知识管理和复杂创作项目。项目仍可选择精简 profile，但这必须是明确的人类选择；配置描述的是组合方式，不是项目价值。

Composition · Adoption · Upgrade

One starting point for composing inquiry, publishing, and project upgrades.

Inquiry Publishing Project Starter is a composition, adoption, and upgrade layer. It helps a project choose how AHICP, PPF, and Vault Interface fit together without becoming a fourth normative framework.

New to the whole ecosystem?

Starter is the machine/configuration entrypoint; ordinary users do not need to understand these technical details first. If you do not yet know why the four projects exist or how they support thinking and long-running work, begin with the AHICP human entrypoint.

Read the complete Human Guide

What the Starter does

The Starter connects independent systems into a project structure that can actually be adopted. It provides templates, configuration, profiles, upgrade rules, and machine-readable state so a project can identify which components it uses, where they come from, and what state they are in.

Compose

Choose research, publishing, research-book, or full research-publication profiles according to the project.

Adopt

Record the upstream revisions a project actually adopts instead of copying independent normative systems into the Starter.

Upgrade

Preserve source commits, adopted commits, and adoption state so upgrades remain explainable and inspectable.

Handoff

Make it possible for a new collaborator to continue from project files, specifications, and machine-readable state.

How the layers relate

AHICP · Human-led AI inquiry protocol
Governs inquiry, evidence, decisions, approvals, handoffs, and responsibility boundaries.
PPF · Personal publishing framework
Governs source material, builds, publication, releases, and rebuildable publishing.
Vault Interface · Public metadata contract
Provides provider-neutral public metadata schemas, templates, and validators; private vault state, working memory, and deployment control planes remain outside this public interface.
Starter · Composition entry point
Composes, adopts, validates, and upgrades these systems according to project needs.

Default project posture

New projects default to full AHICP + full PPF + Vault Interface. Original or unpublished source remains private by default. Continuous Web may be prepared at the same time, but remains restricted until explicit public-release authorization and is protected by Cloudflare Access or an equivalent server-side policy. Repository files store only an access-policy reference, never the actual password or secret. Reduced profiles are used only after explicit human selection.

What it supports

The Starter is suited to personal research, academic writing, research books, knowledge management, and complex creative work that needs durable context, inspectable collaboration, and a stable publication process. Reduced profiles remain available, but selecting one is an explicit human decision; a profile describes composition, not project value.
